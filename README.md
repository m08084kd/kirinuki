# kirinuki ✂️

YouTube の URL を貼るだけで、**盛り上がった箇所を自動で見つけて 30〜60 秒の切り抜き動画**を作るツールです。
ブラウザで使うアプリと、コマンドラインの両方で使えます。

## アプリで使う (おすすめ)

### 起動

Python 3.9 以上が必要です ([ダウンロード](https://www.python.org/downloads/)。Windows ではインストール時に「Add python.exe to PATH」にチェック)。

| OS | 起動方法 |
|---|---|
| Windows | `start_windows.bat` をダブルクリック |
| Mac | `start_mac.command` をダブルクリック (初回は右クリック →「開く」) |
| Linux | `./start_mac.command` を実行 |

初回だけセットアップに数分かかります。終わるとブラウザで `http://127.0.0.1:8765/` が開きます。

pip で入れた場合は `kirinuki-app` で起動できます。

### 使い方

1. YouTube の URL を貼って **「切り抜く」** を押す
2. 進み具合 (動画情報 → 盛り上がり解析 → 書き出し → 完了) が表示されます
3. 終わると **盛り上がりグラフ** と切り抜き動画が並びます
   - グラフの網掛け = 切り抜いた区間。クリックするとその動画へ移動
   - 各動画はその場で再生でき、「ダウンロード」「YouTube で見る」ボタン付き
4. 「📂 保存フォルダを開く」で保存先を開けます (既定: ホームフォルダの `kirinuki_clips`)

本数・長さ・前振りの秒数・縦型 (ショート用 1080×1920) は画面で指定できます。前回の設定は記憶されます。
複数の URL を続けて入れると順番に処理され、「履歴」から結果を見返せます。

> アプリは自分のパソコンの中だけで動きます (`127.0.0.1`)。外部からはアクセスできません。
> アプリを閉じるには、起動したウィンドウで Ctrl+C を押すか、ウィンドウを閉じてください。

## コマンドラインで使う


## 盛り上がりの判定方法

取れるデータを組み合わせて、1秒ごとの「盛り上がりスコア」を出します。

| シグナル | 内容 | 重み |
|---|---|---|
| **最も再生された部分** | YouTube の再生バー上のグラフ (heatmap)。みんなが見返した場所 | 0.40 |
| **チャットリプレイ** | 配信アーカイブのコメント数。`草` `www` `!!` `神` `8888` などは重め、スパチャはさらに重め。コメントの遅れ (既定5秒) を補正 | 0.35 |
| **音量** | 叫び・笑い声など。配信ごとの普段の声量との差で判定 | 0.25 |

- 取れなかったシグナルは除外して、残りで重みを付け直します (普通の動画ならチャットなし、再生数の少ない動画なら heatmap なし)。
- スコアの山を中心に**前振り10秒 + 山場 + 余韻5秒**を切り出し、30〜60秒に収めます。
- 切れ目はセリフの途中にならないよう、前後数秒の静かな瞬間に寄せます。
- 切り抜き同士は重なりません。盛り上がりが弱すぎる候補は出しません。

## インストール (コマンドライン用)

Python 3.9 以上と ffmpeg が必要です。

```bash
pip install .
# ffmpeg をシステムに入れられない場合
pip install ".[ffmpeg]"
```

### オプション

```bash
# 基本 (上位3件を ./clips に書き出し)
kirinuki "https://www.youtube.com/watch?v=..."

# 5件、20〜45秒、縦型ショート (1080x1920、ぼかし背景) で
kirinuki "URL" -n 5 --min 20 --max 45 --vertical

# 検出結果だけ確認 (動画は作らない)
kirinuki "URL" --dry-run

# 手元の動画ファイルでも使えます (音量で判定。チャットJSONがあれば併用)
kirinuki video.mp4 --chat-file video.live_chat.json
```

| オプション | 説明 |
|---|---|
| `-n, --count` | 切り抜きの数 (既定 3) |
| `--min` / `--max` | 最短 / 最長の秒数 (既定 30 / 60) |
| `-o, --output` | 出力フォルダ (既定 `./clips`) |
| `--vertical` | 縦型 1080x1920 で出力 |
| `--dry-run` | 候補の表示とレポートの出力だけ |
| `--lead-in` | 山場の前に入れる前振りの秒数 (既定 10) |
| `--chat-delay` | コメントが出来事から遅れる秒数 (既定 5) |
| `--no-audio` / `--no-chat` / `--no-heatmap` | そのシグナルを使わない |
| `--full-download` | 動画全体をDLしてから切る (区間DLがうまくいかない時に) |
| `--max-height` | DLする画質の上限 (既定 1080) |

出力フォルダには動画のほかに `*_report.json` (各切り抜きの時刻・スコア・YouTube リンク) が保存されます。

### アプリの起動オプション

```bash
kirinuki-app --port 8765 --output ~/Videos/kirinuki --no-browser
```

## しくみ

1. `yt-dlp` で動画情報・heatmap・チャットリプレイを取得
2. 解析用に**音声だけ**をダウンロードして音量を計測 (長時間配信でも軽い)
3. シグナルを合成してスコア化 → 切り抜き区間を決定
4. 選んだ区間だけをダウンロードし、ffmpeg で正確にカット (失敗時は全体DLに自動切替)

## トラブルシューティング

- **動画情報を取得できない / ダウンロードに失敗する**: YouTube の仕様変更で yt-dlp が古くなっていることがよくあります。`pip install -U yt-dlp` で更新してください (ランチャーは起動時に自動更新します)。
- **ポートが使用中**: `kirinuki-app --port 8766` のように別の番号で起動してください。

## 開発

```bash
pip install -e ".[dev]"
pytest
```

## 注意

切り抜き動画の公開は、元動画の権利者のガイドライン (切り抜き許諾の有無など) に従ってください。
